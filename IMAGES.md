# Как подгрузить картинки в бота

Картинки **опциональны**: если файла нет, бот отправит только текст. Форматы: **.png**, **.jpg**, **.jpeg**, а для экранов испытания и меню ещё и **.gif** (анимация важнее картинки с тем же именем).

---

## 1. Испытания (flow)

**Папка:** `flow_images/`

| Файл | Когда показывается |
|------|--------------------|
| `trial_intro` | Вступление (Попая Тут) |
| `trial_direction` | Выбор направления |
| `trial_quiz_1` … `trial_quiz_5` | Вопросы квиза |
| `trial_final` | Финал (банка шпината) |

Примеры: `trial_intro.png`, `trial_direction.jpg`

---

## 2. Экраны меню и разделов

**Папка:** `screen_images/`

| Файл | Когда показывается |
|------|--------------------|
| `menu` | Главное меню, возврат в меню |
| `programs` | Программы тренировок |
| `package_starter` | Пакет STARTER |
| `package_online_crew` | Пакет ONLINE CREW |
| `package_vip` | Пакет VIP КАПИТАН |
| `package_hybrid` | Пакет ГИБРИД |
| `package_sent` | «Заявка отправлена» |
| `referral` | Реферальная программа |
| `gifts_intro` | Подарки — проверка подписки |
| `gifts_ok` | Подарки — список подарков |
| `materials` | Полезные материалы |
| `contact` | Связаться с капитаном |

Примеры: `menu.png`, `programs.jpg`, `package_starter.png`

---

## 3. Гайды (уже настроено)

**Папки:** `guide_images_men/`, `guide_images_women/`

Файлы: `guide_1`, `guide_2`, … (мужской — 10 шт., женский — 15 шт.)

Примеры: `guide_1.png`, `guide_2.jpg` и т.д.

---

## Что сделать

1. Создай или возьми картинки.
2. Положи их в нужную папку с подходящим именем (без расширения в коде — бот сам проверит .png / .jpg / .jpeg).
3. Перезапусти бота. Дальше картинки подхватятся автоматически.
