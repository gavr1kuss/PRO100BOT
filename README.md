# PRO100BOT - Telegram бот для фитнес-тренера

## 📋 Описание

Telegram-бот для сбора заявок от клиентов фитнес-тренера. Бот проводит опрос пользователя, собирает информацию о целях, опыте, ограничениях и контактные данные, после чего отправляет отчет администратору.

## 🏗️ Структура проекта

```
PRO100BOT/
├── handlers/           # Обработчики событий
│   ├── menu.js        # Главное меню, FAQ, гайды
│   ├── direction.js   # Выбор направления тренировок
│   ├── quiz.js        # Опросник (уровень, травмы, цели и т.д.)
│   └── registration.js # Регистрация (имя, телефон, отчет)
├── db.js              # Работа с базой данных SQLite
├── keyboards.js       # Клавиатуры для бота
├── texts.js           # Текстовые сообщения
├── stages.js          # Константы этапов (stages)
├── index.js           # Главный файл, точка входа
├── package.json       # Зависимости проекта
└── .env.example       # Пример файла с переменными окружения
```

## 🚀 Установка

1. Установите зависимости:
```bash
npm install
```

2. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

3. Заполните `.env`:
- `BOT_TOKEN` - токен бота от @BotFather
- `ADMIN_CHAT_ID` - ваш Telegram ID (можно узнать через команду `/myid` в боте)

4. Запустите бота:
```bash
npm start
```

Для разработки с автоперезагрузкой:
```bash
npm run dev
```

## 📊 Поток работы бота

1. **Главное меню** - пользователь выбирает действие
2. **Выбор направления** - Гипертрофия, Пауэрлифтинг, Фитнес, ССШ
3. **Выбор формата** - Онлайн, Зал, Смешанный
4. **Выбор услуги** - Консультация, Программа, Персональные тренировки, Сопровождение
5. **Опросник**:
   - Уровень опыта
   - Травмы/ограничения
   - Оборудование
   - Дни тренировок
   - Цель
   - Город
6. **Предложение** - показ итогового плана
7. **Регистрация** - сбор имени и телефона
8. **Отчет** - отправка данных администратору

## 🔧 Архитектура

Проект построен по модульному принципу:

- **handlers/** - каждый файл отвечает за свою область логики
- **stages.js** - централизованное управление этапами
- **db.js** - изолированная работа с БД
- **keyboards.js** - все клавиатуры в одном месте
- **texts.js** - все тексты в одном месте

Такая структура упрощает:
- Поиск нужного кода
- Добавление новых функций
- Исправление ошибок
- Тестирование

## 📝 База данных

Используется SQLite с таблицей `users`, которая хранит:
- `user_id` - ID пользователя Telegram
- `stage` - текущий этап опроса
- Все данные опросника (direction, format, service, level, и т.д.)

## 🎯 Основные команды

- `/start` - начать работу с ботом
- `/myid` - узнать свой Telegram ID
