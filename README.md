# PRO100BOT

Telegram-бот фитнес-тренера («капитана» [@papochka86](https://t.me/papochka86)): бот [@Pro100giryabot](https://t.me/Pro100giryabot), канал [@FitnessNaMaximum](https://t.me/FitnessNaMaximum).

Бот знакомит человека с тренером через короткое «испытание»-квиз, дарит гайд за подписку на канал, рассказывает о пакетах тренировок и собирает заявки. Заявки и важные события приходят админу в Telegram.

## 📊 Что умеет бот

1. **Испытание** (`/start`): вступление → выбор направления → квиз из 5 вопросов (опыт, травмы, оборудование, дни в неделю, цели).
2. **Подарок**: гайд «Как правильно сдавать анализы», мужской (10 картинок) или женский (15). Выдаётся подписчикам канала.
3. **Главное меню**:
   - 💪 Программы тренировок: направление (гипертрофия, пауэрлифтинг, фитнес, ССШ) → пакет (STARTER, ONLINE CREW, VIP КАПИТАН, ГИБРИД) → заявка с именем и телефоном;
   - 🎯 Реферальная программа: личная ссылка и счётчик приглашённых (засчитываются только новые пользователи);
   - 🎁 Подарки за приглашённых друзей (для подписчиков канала);
   - 📚 Полезные материалы, 📞 связь с капитаном, 📥 гайд заново.

Админу приходят: новый пользователь, пройденный квиз, неполная и полная заявка на пакет, заявка на пробную тренировку.

## 🚀 Запуск на своём компьютере

Нужен Node.js 18 или новее.

```bash
npm install
cp .env.example .env     # в Windows: copy .env.example .env
# впиши в .env BOT_TOKEN и ADMIN_CHAT_ID
npm start
```

`npm run dev` делает то же самое, но перезапускает бота при изменениях в коде.

Один токен нельзя запускать в двух местах одновременно: Telegram отдаёт сообщения только одному экземпляру. Пока бот работает на сервере, для экспериментов заведи отдельного тестового бота у @BotFather.

## ⚙️ Настройки (.env)

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `ADMIN_CHAT_ID` | Telegram ID, куда приходят заявки и уведомления (узнать: команда `/myid` в боте) |
| `CHANNEL_USERNAME` | канал для проверки подписки, по умолчанию `@FitnessNaMaximum` |
| `CAPTAIN_USERNAME` | username тренера без @, по умолчанию `papochka86` |
| `BOT_USERNAME` | username бота для реферальных ссылок, по умолчанию `Pro100giryabot` |
| `DB_PATH` | путь к файлу базы, по умолчанию `bot.sqlite` рядом с кодом |

Чтобы проверка подписки работала, бот должен быть **администратором канала**. Иначе Telegram не показывает ему подписчиков и подарки не получит никто. В логе при этом появится «Не удалось проверить подписку на канал».

Всё хранится в одном файле `bot.sqlite`, в таблице `users`: этап сценария, ответы квиза, имя, телефон, выбранный пакет, реферальный код и кто пригласил. В git база не попадает. На сервере её стоит время от времени копировать себе (см. [DEPLOY.md](DEPLOY.md)).
