# Картинки для испытаний (User Flow)

Положи сюда файлы — бот отправит их перед текстом. Если файла нет, будет только текст.

**Форматы:** `.png`, `.jpg`, `.jpeg`

## Список файлов

| Файл | Экран |
|------|--------|
| `trial_intro` | Вступление (Попая Тут) |
| `trial_direction` | Выбор направления |
| `trial_quiz_1` | Квиз: уровень опыта |
| `trial_quiz_2` | Квиз: травмы |
| `trial_quiz_3` | Квиз: оборудование |
| `trial_quiz_4` | Квиз: дни тренировок |
| `trial_quiz_5` | Квиз: цель |
| `trial_final` | Финал (банка шпината) |

Примеры: `trial_intro.png`, `trial_direction.jpg`
