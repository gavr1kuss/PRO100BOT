# Папка для картинок гайда для мужчин

Поместите сюда 10 картинок с именами:
- `guide_1.jpg` (или `.jpeg`, `.png`)
- `guide_2.jpg`
- `guide_3.jpg`
- ...
- `guide_10.jpg`

Бот автоматически найдет картинки в форматах: `.jpg`, `.jpeg`, `.png`

Если меняешь количество картинок, поправь `TOTAL_IMAGES_MEN` в `handlers/guide.js`.
