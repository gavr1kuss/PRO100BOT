# Папка для картинок гайда для женщин

Поместите сюда 15 картинок с именами:
- `guide_1.jpg` (или `.jpeg`, `.png`)
- `guide_2.jpg`
- `guide_3.jpg`
- ...
- `guide_15.jpg`

Бот автоматически найдет картинки в форматах: `.jpg`, `.jpeg`, `.png`

Если меняешь количество картинок, поправь `TOTAL_IMAGES_WOMEN` в `handlers/guide.js`.
