# Картинки для экранов (меню, программы, подарки и т.д.)

Положи сюда файлы — бот отправит их перед текстом. Если файла нет, будет только текст.

**Форматы:** `.png`, `.jpg`, `.jpeg`

## Список файлов

| Файл | Экран |
|------|--------|
| `menu` | Главное меню (штурвал) |
| `programs` | Программы тренировок — выбор направления |
| `package_starter` | Пакет STARTER |
| `package_online_crew` | Пакет ONLINE CREW |
| `package_vip` | Пакет VIP КАПИТАН |
| `package_hybrid` | Пакет ГИБРИД |
| `referral` | Реферальная программа |
| `gifts_intro` | Подарки — экран проверки подписки |
| `gifts_ok` | Подарки — «Добро пожаловать в команду» |
| `materials` | Полезные материалы |
| `contact` | Связаться с капитаном |
| `package_sent` | «Заявка отправлена» после записи на пакет |

Примеры: `menu.png`, `programs.jpg`, `package_starter.png`
